操作说明与配置流程

蛙云采用标准机场订阅模式，配置一次即可长期使用。请按照下列步骤操作，整个过程通常只需几分钟。

1. 订阅获取

在官网完成套餐购买后，进入用户中心复制订阅链接。该链接包含您的节点配置，支持自动更新。请妥善保管，勿公开分享以免流量被盗用。

2. 选择并下载客户端

Windows：Clash Verge、v2rayN 或 NekoBox。macOS：ClashX.Meta、Stash。Android：Clash Meta for Android、v2rayNG。iOS：Shadowrocket、Quantumult X 或 Stash。Linux：clash 或 sing-box 命令行/图形前端。

请从各软件官方仓库或本站指引下载，确保版本较新以获得最佳兼容性。

3. 导入订阅并连接

启动客户端，找到订阅或 Profiles 功能，选择从 URL 添加，粘贴链接后更新。等待节点加载完成，测试延迟，选择合适节点开启系统代理或增强模式。浏览器或应用即可走加速通道。

4. 日常使用与故障排除

根据内容类型切换节点：流媒体用解锁标识线路，游戏用低延迟 IPLC。若连接失败，先更新订阅、更换节点或协议（如从 ws 换 grpc），检查本地防火墙。持续问题可通过工单反馈，旗舰用户享优先处理。

常见问题

蛙云和普通VPN有什么区别？

蛙云以机场订阅形式提供，用户通过一次订阅获得多个节点与协议选择，比传统单一VPN更灵活，且针对流媒体解锁和游戏加速做了专门优化，同时支持自己喜爱的客户端。

如何下载蛙云官方客户端？

蛙云本身以订阅为核心，推荐使用成熟开源客户端。本站配置流程页面列出了各系统推荐软件及其获取方式。直接搜索软件名加官方即可，导入蛙云订阅即可使用全部节点。

年付和月付可以随时切换吗？

可以。当前周期结束后可选择新的付费周期。年付用户如需提前变更，可联系客服按剩余折算处理。建议根据使用稳定性选择年付以节省费用。

节点速度慢或无法解锁怎么办？

首先更新订阅获取最新节点，然后手动测速选择延迟低、当前负载轻的线路。流媒体问题多因节点 IP 被识别，切换至带解锁或原生标签的节点即可。游戏则优先 IPLC。

是否提供退款或试用？

新用户首次订阅可享短时测试节点体验基础连通性。因数字服务特性，一经使用的流量套餐通常不支持无理由退款，但遇到重大线路故障我们会补偿流量或延期。具体以用户中心说明为准。

团队版如何管理多名成员？

团队版提供更高设备上限与流量池，管理员可分配子订阅或统一链接。支持定制分流（例如办公软件直连、视频走代理），并有专属客户经理协助初期配置与后续优化。
